# Kotoba Studio M0 Skeleton Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A runnable local-first web app + API where a user can register a source, capture a screen region on macOS, OCR it, save a line, confirm a term into cards, and review with FSRS on desktop or phone (LAN PWA).

**Architecture:** Single FastAPI process (SQLite via SQLAlchemy 2 + Alembic) is the only data owner; it serves the built Vue 3 SPA on one port so phones on the LAN reach the same app. Platform-specific capture/OCR live behind provider interfaces so they can be faked in tests and swapped per OS.

**Tech Stack:** Python 3.12, FastAPI 0.141, SQLAlchemy 2.0, Alembic 1.20, py-fsrs 6.3, fugashi 1.5 + unidic-lite, mss 10, Pillow 12, pyobjc-framework-Vision (macOS), httpx, keyring, segno, genanki; Vue 3.5, Vite 8, TypeScript, vue-router 5, Pinia 4, Tailwind 4, vite-plugin-pwa 1.3, Vitest 5.

**Spec:** `docs/superpowers/specs/2026-09-15-kotoba-studio-design.md`

## Global Constraints

- Python >= 3.12; manage with `uv` (server/pyproject.toml). Node >= 22, npm.
- API prefix `/api`; errors as `{"error": {"code": str, "message": str}}`.
- Server port default 8720; bind 127.0.0.1 by default, `--host 0.0.0.0` for LAN.
- Data dir from `KOTOBA_DATA_DIR` env or `platformdirs.user_data_dir("KotobaStudio")`; tests always set `KOTOBA_DATA_DIR` to a tmp dir.
- Never import platform-only modules (Vision, winocr, mss) at module import time of the app; import lazily inside providers.
- Session-quiz results never mutate FSRS fields (`stability, difficulty, due, last_review, fsrs_state, fsrs_step`).
- A card is served for scheduled review only if `review_owner in (device.kind, 'any')`.
- Card fronts never include screenshot or the full sentence with the answer visible.
- UI copy is Simplified Chinese; code identifiers English.
- Commit after every task with a conventional-commit message ending in `Co-Authored-By: Claude Fable 5.1 <noreply@anthropic.com>`.

### Task 2: Japanese text utilities (kana, normalize, tokenizer, contractions)

**Files:** `server/kotoba/services/jp/{kana,normalize,tokenizer,contractions}.py`, `server/kotoba/data/jp_contractions.json`; tests `server/tests/test_jp.py`.

**Interfaces:**
- `kana.to_hiragana(s) -> str`, `kana.to_katakana(s) -> str`, `kana.is_kanji(ch) -> bool`, `kana.has_kanji(s) -> bool`, `kana.kana_equal(a, b) -> bool` (compares after hiragana conversion and `ー`/long-vowel tolerance off; exact after conversion).

- `tokenizer.Token` dataclass: `surface, lemma, reading (hiragana), pos1, pos2, base, start, end`; `tokenizer.tokenize(text) -> list[Token]` (fugashi Tagger singleton; reading from `feature.kana` converted to hiragana; `base` from `orthBase` or surface).
- `contractions.expand(surface) -> str | None` (lookup table), `contractions.load() -> dict[str,str]`.
