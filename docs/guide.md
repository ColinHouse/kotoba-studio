# 头三件事

1. **设置 → 词典 → 安装 JMdict**（约 25 MB）。不装的话，收件箱里点词查不到释义。
2. **作品 → 添加一部** → 开始会话。
3. **采集 → 框选对话框区域**。macOS 第一次会因为没有屏幕录制权限只截到壁纸，
   见[平台说明](/platforms)。

## 之后的日常

采集页框选后 <kbd>⌘</kbd>/<kbd>Ctrl</kbd>+<kbd>Enter</kbd> 收藏台词 →
收件箱点词建卡 → 复习页复习。

台词也可以不靠截图——直接[导入字幕、EPUB 或 mokuro 漫画](/integrations#把文本导入一部作品)，
或者[接一个 Hook 工具](/integrations#hook-协议)。

## 截图还是 Hook？

这不是二选一，是**不同的游戏给不同的输入**：

- **Hook** 拿到的是原始文本，准确、零延迟，但要那个游戏有可用的钩子。
- **截图 + OCR** 什么都能吃，代价是 OCR 会错、要框选区域。

两条路进来的句子在收件箱里长得一样，后面的流程完全一致。
